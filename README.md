# Hnefatafl README

Hnefatafl is a 2-player board game invented by the Vikings before chess emerged.

A Viking horde (black) is attacking the defending Vikings (white). Winning the game requires
different stragegy for the attackers vs the defenders. The defending side (white) has a simple
goal: the king must escape to one of the four corners of the board. The attacking side wins by
surrounding the king on all four sides, thereby capturing the king.

## Basic Rules

- The board is 11x11 (rather than8x8 like chess)
- Black goes first always
- Black wins if it surrounds the king
- White wins if the king escapes to one of the four corners
- There are 24 black attackers, 12 defenders, plus the defending king
- All game pieces move like a rook in chess (horizontally or vertically only)
- Pieces cannot move through other pieces on the board
- Pieces capture enemy pieces by surrounding them on 2 sides
- King is only captured when surrounded on all 4 sides
- Only the king can occupy a "king square", the 4 corners and the center square
- The "king squares" act as an enemy. Do not linger next to them
- The king is a powerful piece (think chess queen). Use it to attack, not just run

For full game rules, see: https://aagenielsen.dk/Copenhagen_Hnefatafl_11x11.pdf

## Game Features

- Mobile first: works on phones, tablets and computers
- Hnefatafl is playable in a browser by two human players, human against ai, or ai against ai
- The game can be saved at any point in HEN (Hnefatafl Encoded Notation), a plain text file
- HEN files can be loaded to restore a previously saved game
- The HEN file is built and displayed real-time as the game progresses
- Game controls are any combination of keyboard, mouse or trackpad
- Supports common browsers: Chrome, Microsoft Edge, Safari, DuckDuckGo, Brave, Firefox, etc..

## Basic Usage

The game is a web game requiring no plug-ins. It simply uses the HTML, CSS and Javascript already built into your browswer. You can download it and play it locally (index.html).

Or play the game online at: https://drewagislason.github.io/Drews-hnefatafl/src
